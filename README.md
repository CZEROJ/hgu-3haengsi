# 3행시 A4 출력

한동대 생일 축하 게시판용 도구입니다.
3행시를 입력하면 **한 글자당 A4 한 장씩** 인쇄용으로 만들어 줍니다.
워드에서 글자 키우고 방향 돌리고 한 장씩 만들 필요가 없습니다.

**→ https://czeroj.github.io/hgu-3haengsi/**

## 기능

- 이름을 치면 글자 수만큼 행이 자동 생성
- 내용 칸에서 Enter로 줄바꿈 (줄이 바뀌면 본문 열에 맞춰 정렬)
- 글꼴 12종 — 서체마다 다른 실제 글자 크기를 재서 자동 보정
- 이름 글자와 본문 글자의 크기를 따로 조절
- 이름 글자 색 6종
- 떼는 날짜를 마지막 장 오른쪽 아래에 인쇄
- 붙였을 때의 배치를 실제 비율로 미리보기
- 인쇄 장수와 비용(흑백 장당 50원) 자동 계산
- PDF 저장 — 글꼴이 파일에 담겨 다른 컴퓨터에서도 똑같이 인쇄됩니다
- Word(.docx) 파일로 저장 — 워드에서 고쳐 쓸 때만

## 구조

HTML 파일 하나입니다. 서버도, 빌드도, 설치도 필요 없습니다.
입력한 내용은 브라우저에만 저장되고 어디로도 전송되지 않습니다.

## 인쇄할 때

인쇄 창에서 **여백 없음**, **배율 100%**("페이지에 맞춤" 끄기)로 두세요.
배율을 안 끄면 글자가 작게 나옵니다.

## 인쇄용 컴퓨터가 따로 있다면

만든 자리에서 **PDF로 저장**한 뒤 파일을 옮기세요.
PDF는 글꼴을 파일 안에 담기 때문에, 그 컴퓨터에 글꼴이 없어도
화면에서 본 그대로 인쇄됩니다. 사이트에 접속할 필요도 없습니다.
